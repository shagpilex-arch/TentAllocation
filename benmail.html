BenMail

A very basic Windows mail program, a bit like a simple Outlook-style app, intended to do the essentials without turning into a giant mail suite.

Available on request

Overview

BenMail is a small Windows mail client project. The current package is a ClickOnce-style Windows deployment, with versioned application files and a `setup.exe` in the project folder.

It uses MailKit and MimeKit, which means the project is built around real mail protocol and message handling libraries rather than being a webmail wrapper.

What it is for

  • Basic mail handling Intended for reading and sending messages without the heavy enterprise feel.
  • Unified inbox direction The aim is to bring essentials into one simple place.
  • Windows desktop app Packaged as a Windows application rather than a web service.
  • MailKit/MimeKit based Uses established .NET libraries for mail transport and message parsing.
  • Small-scope utility Meant to do the useful basics, not replace every advanced Outlook feature.
  • Early packaged build Current deployment files exist, but the public release route is still intentionally cautious.

Current status

Available on request. A packaged build exists in the project folder, but I am not linking it directly from the public site yet.

This is still a hobby app and may be rough around the edges.

Notes

BenMail is not trying to be a corporate email platform. It is a practical experiment in a simpler mail client, with the useful basics taking priority over polish and endless settings.

If you want to try the current build, use the contact page and I can share it with the right caveats.
