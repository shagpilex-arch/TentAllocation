Camp Tent Allocation

A visual planning tool for organising who is sleeping in which tent at camp, mainly for Scout camps and similar group events.

Available now

Overview

Camp Tent Allocation is designed for planning camp tent allocations without the usual spreadsheet wrestling. Add people, add tents, arrange the camp layout visually, and see the groupings clearly as you work.

It is most useful for Scout camps, youth group camps, and similar events where you need a clear plan for who sleeps where.

What it is for

  • Planning tent groups Drag people into tents and keep the whole allocation visible.
  • Avoiding messy spreadsheets Use a purpose-built layout instead of trying to make cells behave like a campsite.
  • Friend and foe links Keep friends together or mark people who should not share a tent.
  • Clear warnings Spot unallocated people and allocation issues while planning.
  • Printable output Export a tidy tent allocation table for leaders, parents, or camp records.
  • Local camp files Camp data is stored locally on your computer.

Current status

Available now. Camp Tent Allocation remains available from the Microsoft Store.

The tent allocation features from this standalone tool are now also included in Camp Planner, the new combined Bear Camp program.

Supporter web edition

A next-level web version is now available.

Camp Tent Allocation now has a browser-based version for supporters who leave a tip. It keeps the familiar planner workflow, but adds the piece that changes camp admin completely: live device-to-device collaboration.

No install, no passing files back and forward, no wondering who has the latest copy. Two leaders can work on the same camp plan from different laptops, tablets, phones, or desktops and see updates arrive in real time.
