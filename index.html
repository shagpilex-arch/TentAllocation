Built for the real camp planning job

The app is designed for a practical field-style workflow: drag tents around, drop people into allocations, see warnings immediately, and print something adults can actually use.

Visual tent planning

Use a grass-style canvas with draggable tent cards, people cards, mess tents, storage tents, fire points and flag poles.

People and roles

Add campers, adults and young leaders with male/female icons so groups can be checked quickly at a glance.

Friend groups

Link friends together. Dragging one person in a linked group moves the connected group together.

Allocation warnings

Warnings are shown for mixed-gender camper tents, camper/adult mixing, camper/young leader mixing, insufficient adults, foe conflicts and unallocated people.

Printable outputs

Create a clean tent allocation table and export it to PDF for A4 printing. Tent tags can also be exported.

Local camp files

Projects save as readable JSON camp files. Nothing is uploaded and there is no account or cloud service.

How it works

A typical camp plan can be put together in a few simple steps.

Add the camp details

Set the camp name and date, then add the tents and any site items you want shown on the planning field.

Add people

Add campers, adults and young leaders, then create friend or foe links where those relationships matter.

Drag, check, print

Drag people into tents, review warnings, save the camp file and export the tent allocation table to PDF.

Questions

Does it need the internet?

No. After download, the app works offline. Camp files are stored locally on the computer.

Is there a login or cloud account?

No. There is no login, no cloud sync and no online storage.

What does it export?

The app exports PDF files for printable tent allocation tables and tent tags.

Is this an official Scouts product?

No. It is an independent tool made to help with practical camp planning.
