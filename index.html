Overview

Tent Allocation is a Windows desktop application built to help Scout leaders quickly and fairly assign young people to tents for camp. It removes the hours of manual juggling that come with large groups, patrol splits, and personal preferences.

The tool is free to use and requires no installation. Simply download the .exe, run it, and you're ready to go.

Requirements

  • Windows 10 or Windows 11
  • No additional software or runtime required
  • No internet connection needed once downloaded
Tent Allocation is a standalone executable. You do not need to install anything — just download and run.

Getting started

  1. Download the TentAllocation.exe file from the Home page.
  2. Windows may show a SmartScreen warning the first time. Click More info → Run anyway — the file is safe.
  3. The application will launch directly with no installation wizard.
  4. You're ready to start planning your camp.

Using the app

Adding scouts

Enter each young person's name and any relevant details such as patrol membership or preferences. You can type them in directly or paste a list.

Setting up tents

Define how many tents you have and the maximum capacity of each. The app will ensure no tent exceeds its limit.

Running the allocation

Once your scouts and tents are set up, click Allocate. The app will distribute scouts across tents, respecting any constraints you have set.

Tip: You can manually drag and drop scouts between tents after the initial allocation if you want to make tweaks.

Exporting

Use File → Export to save your tent list. Supported formats include a printable PDF layout and a plain text list suitable for copying into emails or notice boards.

FAQ

Is the tool really free?

Yes, completely. A voluntary £1 tip is appreciated but never required. See the Home page for details.

Will it work on a Mac?

Currently Windows only. If there is demand for a Mac version, please use the Request a Feature form on the Home page.

My antivirus flagged the file — is it safe?

Yes. Because Tent Allocation is not a widely distributed commercial application, some antivirus tools flag new unsigned executables as a precaution. The file is clean. If you are unsure, you can scan it at VirusTotal.com before running.

Something isn't working — how do I get help?

Use the Get in touch form on the Home page and describe what you're seeing. Include your Windows version if possible.
