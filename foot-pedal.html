Foot Pedal

An Olympus RS24 foot pedal mapper that reads pedal presses and turns them into configurable Windows keyboard macros.

Available on request

Overview

Foot Pedal is a Windows utility for the Olympus RS24 foot switch. It reads the three pedal buttons, labelled in the project as Listen, Rewind, and FastForward, then maps them to keyboard output for the foreground app.

The default macro file maps Listen to Space, Rewind to Left, and FastForward to Right, but the bindings can be changed in a JSON config file.

What it does

  • Reads the RS24 pedal Connects to the Olympus RS24 over WinUSB and listens for pedal press and release events.
  • Maps three pedals Handles Listen, Rewind, and FastForward as separate buttons.
  • Sends keyboard output Can tap keys, hold keys, or run a sequence of macro steps.
  • Uses JSON macros Loads a `macros.json` file so mappings can be edited without rebuilding the tool.
  • Can run in the background Includes installer/startup helper scripts for a hidden mapper process.
  • Includes diagnostic modes Can list devices, show raw reports, and validate macro config.

Current status

Available on request. The project folder contains the mapper, macro config, installer script, and driver-related files, but I am not publishing a direct download link here yet.

Because this project can involve USB driver binding, distribution needs to be handled carefully and explained plainly.

Notes

The installer can use an existing WinUSB setup, a bundled local driver path, or external tools such as Zadig depending on the machine. I am deliberately not making broad claims about driver signing, safety, or compatibility until the release route is tidier.

If you need this tool, use the contact page and I can share the current package with context.
