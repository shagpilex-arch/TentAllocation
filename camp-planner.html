Camp Planner

The new all-in-one Bear Camp program for planning tents, people, chores, menus, kit, schedules, and camp paperwork in one Windows app.

Available now

Overview

Camp Planner brings the main Bear Camp planning jobs into one program. It includes the features from Camp Tent Allocation and Camp Chores, so leaders can keep sleeping arrangements and duty rotas in the same camp file.

It is built for Scout camps and similar group events where the admin crosses over: people, tents, rotas, menus, kit, daily plans, and exportable paperwork all need to stay aligned.

What it includes

  • Tent allocation Arrange who sleeps where, with the planning features from Camp Tent Allocation included.
  • Camp chores Build chore rotas and assign duties using the Camp Chores planning features.
  • Personnel Keep people, teams, dietary notes, medical notes, and camp details together.
  • Menus Plan meals, pudding, dietary notes, and day-by-day menu checks.
  • Kit lists Track group kit and participant kit without starting another spreadsheet.
  • The Plan Build a camp schedule for activities, timings, teams, tents, or individuals.
  • Exports Produce camp packs, PDFs, tent outputs, chore rotas, menu files, kit lists, and CSV folders.
  • One camp file Keep the linked parts of camp admin together instead of splitting them across separate tools.

Includes the older tools

Camp Planner includes Camp Tent Allocation and Camp Chores features.

The older pages remain on this site for people who still use those individual programs, but Camp Planner is the new combined release.
